# 3.2 Prompts プロンプト管理

## 機能説明

Prompts 機能は、システムプロンプトのブロックを管理します。システムプロンプトは AI の動作や回答スタイルに影響します。

CC Switch を使用すると：

- 複数のプロンプトブロックを作成
- いくつかのブロックを選び、ドラッグで並べて完全なシステムプロンプトに結合
- 結合結果をプレビューしてから Agent ファイルへ適用
- デバイス間でプロンプト設定を同期

## Prompts パネルを開く

上部ナビゲーションバーの **Prompts** ボタンをクリックします。

## ブロックの作成

### 操作手順

1. 右上の **+** ボタンをクリック
2. 名前を入力
3. Markdown エディタでプロンプトを作成
4. 「保存」をクリック

新しいブロックはリスト末尾に追加され、初期状態では未選択です。適用するまでディスク上のファイルは変わりません。

### Markdown エディタ

エディタは以下を提供します：

- シンタックスハイライト
- リアルタイムプレビュー
- よく使うフォーマットのショートカットキー

### プロンプトの書き方のヒント

**構造化フォーマット**：

```markdown
# 役割定義

あなたはプロのコードレビュー専門家です。

## コア能力

- コード品質分析
- パフォーマンス最適化の提案
- セキュリティ脆弱性の検出

## 回答スタイル

- 簡潔明瞭
- 具体的な例を提供
- 改善提案を提示

## 注意事項

- ビジネスロジックを変更しない
- コードスタイルの一貫性を保つ
```

## 選択、並べ替え、適用

### 下書き

リストのスイッチとドラッグはパネル内の下書きだけを変更し、Agent ファイルへはすぐ書き込みません。検索中はドラッグできません。

### ファイルへ適用

選択と順序が決まったら **ファイルに適用** をクリックします。CC Switch はリスト順に、選択したブロック本文を空行でつないで対象アプリのファイルへ書き込みます。ブロック名は管理 UI 専用で、ファイルには入りません。

未適用の下書きがあるときはアプリ切り替えやページ離脱がブロックされます。**下書きを破棄** で前回適用済みの状態に戻せます。

### 同期先

| アプリ | ファイルパス |
|------|----------|
| Claude | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| Gemini | `~/.gemini/GEMINI.md` |
| Grok Build | `~/.grok/AGENTS.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |
| OpenClaw | OpenClaw 設定ディレクトリの `AGENTS.md` |
| Hermes | `~/.hermes/SOUL.md` |
| Pi | `~/.pi/agent/AGENTS.md` |

Pi の `SYSTEM.md` / `APPEND_SYSTEM.md` とスラッシュコマンドテンプレートは別エディタであり、ブロック結合の対象ではありません。

何も選ばずに適用すると、ほとんどのアプリではファイルを空にし、Pi では `AGENTS.md` を削除します。

## ブロックの編集

1. ブロックの「編集」ボタンをクリック
2. 名前や内容を変更
3. 「保存」をクリック

そのブロックが **すでにファイルへ適用済み** の集合に含まれる場合、内容の保存は適用済みの選択と順序でファイルを直ちに書き直します。下書きのチェック状態は変わりません。

## ブロックの削除

1. ブロックの「削除」ボタンをクリック
2. 削除を確認

ファイルへ適用済みでまだ有効なブロックは削除できません。チェックを外して「ファイルに適用」してから削除してください。

## 外部変更の保護

CC Switch の外で live ファイルが変わっている場合（例: `CLAUDE.md` を直接編集）、次の実書き込みの前にその内容を **無効なバックアップブロック** として保存してから、今回の結合結果を書き込みます。外部変更を既存ブロックへ書き戻すことはありません。

アップグレード前の古い `## ブロック名` 結合形式のファイルは同期済みとみなし、バックアップは作りません。次回の適用で生の結合形式に書き換わります。

初回起動時、そのアプリにプロンプトがまだ無い場合、既存の live ファイルを 1 つの適用済みブロックとして取り込みます。

## アプリ間での使用

Prompts はアプリごとに個別に管理されます：

- Claude に切り替えると Claude のブロックが表示
- Codex に切り替えると Codex のブロックが表示
- 他の対応アプリも同様

複数のアプリで同じ内容を使う場合は、それぞれで作成する必要があります。

## インポート・エクスポート

### ディープリンクで共有

ディープリンクでプロンプトを共有できます。リンクに `enabled=true` がある場合、インポートはそのブロックを適用セットへ **追加** し、他のブロックを無効にせず直ちにファイルへ書き込みます。

### 設定のエクスポートで共有

設定をエクスポートするとすべてのプロンプトが含まれ、インポートで復元できます。
