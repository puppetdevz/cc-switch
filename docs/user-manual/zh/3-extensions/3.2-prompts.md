# 3.2 Prompts 提示词管理

## 功能说明

Prompts 功能用于管理系统提示词块。系统提示词会影响 AI 的行为和回复风格。

通过 CC Switch，你可以：

- 创建多个提示词块
- 勾选若干块、拖拽排序后拼成完整系统提示词
- 预览拼接结果，确认后再写入对应 Agent 文件
- 跨设备同步提示词配置

## 打开 Prompts 面板

点击顶部导航栏的 **Prompts** 按钮。

## 创建块

### 操作步骤

1. 点击右上角 **+** 按钮
2. 输入名称
3. 在 Markdown 编辑器中编写提示词
4. 点击「保存」

新块会追加到列表末尾，默认未勾选，不会立刻改磁盘上的文件。

### Markdown 编辑器

编辑器提供：

- 语法高亮
- 实时预览
- 常用格式快捷键

### 提示词编写建议

**结构化格式**：

```markdown
# 角色定义

你是一个专业的代码审查专家。

## 核心能力

- 代码质量分析
- 性能优化建议
- 安全漏洞检测

## 回复风格

- 简洁明了
- 提供具体示例
- 给出改进建议

## 注意事项

- 不要修改业务逻辑
- 保持代码风格一致
```

## 勾选、排序与应用

### 草稿

列表里的开关和拖拽只改当前面板的草稿，不会立刻写入 Agent 文件。搜索时不能拖拽排序。

### 应用到文件

勾选和顺序确定后，点击 **应用到文件**。CC Switch 按列表顺序把已勾选块的正文用空行拼接，写入对应应用的文件。块名只用于管理界面，不会写进文件。

未应用的草稿会拦住切换应用和返回；也可以点 **丢弃草稿** 恢复到上次已应用的状态。

### 同步目标

| 应用 | 文件路径 |
|------|----------|
| Claude | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| Gemini | `~/.gemini/GEMINI.md` |
| Grok Build | `~/.grok/AGENTS.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |
| OpenClaw | OpenClaw 配置目录下的 `AGENTS.md` |
| Hermes | `~/.hermes/SOUL.md` |
| Pi | `~/.pi/agent/AGENTS.md` |

Pi 的 `SYSTEM.md` / `APPEND_SYSTEM.md` 和斜杠命令模板是另一套编辑器，不走提示词块。

一块都不选并应用时：大多数应用会把文件写成空内容；Pi 会删除 `AGENTS.md`。

## 编辑块

1. 点击块的「编辑」按钮
2. 修改名称或内容
3. 点击「保存」

如果该块属于**已应用到文件**的集合，保存内容后会立刻按已应用的勾选和顺序重写文件。草稿里的勾选不受影响。

## 删除块

1. 点击块的「删除」按钮
2. 确认删除

已应用到文件且仍启用的块不能删除。请先取消勾选并点「应用到文件」，然后再删除。

## 外部修改保护

如果有人在 CC Switch 之外改过 live 文件（例如直接编辑 `CLAUDE.md`），下一次真正写盘前会把当前文件另存为一条**未启用的备份块**，再写入本次拼接结果。不会把外部修改写回任何已有块。

升级前若文件仍是旧的 `## 块名` 拼接格式，会视为已同步，不产生备份；下次应用时改为裸拼接。

首次启动时，若该应用还没有提示词，会把现有 live 文件导入为一条已应用的块。

## 跨应用使用

Prompts 按应用分开管理：

- 切换到 Claude 时，显示 Claude 的块
- 切换到 Codex 时，显示 Codex 的块
- 其他支持提示词的应用同理

如需在多个应用使用相同内容，需要分别创建。

## 导入导出

### 通过深度链接分享

可以生成深度链接分享提示词。若链接带 `enabled=true`，导入后会把该块**加入**已应用集合并立即写盘，不会停用其他块。

### 通过配置导出

导出配置时会包含所有提示词，导入后可恢复。
