# 3.2 Prompts Management

## Overview

The Prompts feature manages system prompt blocks. System prompts influence the AI's behavior and response style.

With CC Switch, you can:

- Create multiple prompt blocks
- Select several blocks, drag to order them, and compose a full system prompt
- Preview the joined text, then apply it to the agent file
- Sync prompt configurations across devices

## Open the Prompts Panel

Click the **Prompts** button in the top navigation bar.

## Create a Block

### Steps

1. Click the **+** button in the top-right corner
2. Enter a name
3. Write the prompt in the Markdown editor
4. Click "Save"

New blocks are appended to the end of the list, start unchecked, and do not change the file on disk until you apply.

### Markdown Editor

The editor provides:

- Syntax highlighting
- Live preview
- Common format shortcuts

### Prompt Writing Tips

**Structured format**:

```markdown
# Role Definition

You are a professional code review expert.

## Core Capabilities

- Code quality analysis
- Performance optimization suggestions
- Security vulnerability detection

## Response Style

- Clear and concise
- Provide specific examples
- Give improvement suggestions

## Notes

- Do not modify business logic
- Maintain consistent code style
```

## Select, Reorder, and Apply

### Draft

Toggles and drag-and-drop in the list only change an in-memory draft. They do not write the agent file immediately. Dragging is disabled while a search filter is active.

### Apply to file

When the selection and order look right, click **Apply to file**. CC Switch joins the checked blocks in list order with a blank line between them and writes the result to that app's file. Block names stay in the UI; they are not written into the file.

An unapplied draft blocks switching apps and leaving the page. **Discard draft** restores the last applied selection.

### Sync Target

| Application | File Path |
|-------------|-----------|
| Claude | `~/.claude/CLAUDE.md` |
| Codex | `~/.codex/AGENTS.md` |
| Gemini | `~/.gemini/GEMINI.md` |
| Grok Build | `~/.grok/AGENTS.md` |
| OpenCode | `~/.config/opencode/AGENTS.md` |
| OpenClaw | `AGENTS.md` in the OpenClaw config directory |
| Hermes | `~/.hermes/SOUL.md` |
| Pi | `~/.pi/agent/AGENTS.md` |

Pi's `SYSTEM.md` / `APPEND_SYSTEM.md` and slash-command templates are separate editors and are not composed as blocks.

Applying with nothing selected writes an empty file for most apps, and deletes `AGENTS.md` for Pi.

## Edit a Block

1. Click the "Edit" button on the block
2. Modify the name or content
3. Click "Save"

If the block is in the **already applied** set, saving its content immediately rewrites the file using the applied selection and order. The draft checkboxes are unchanged.

## Delete a Block

1. Click the "Delete" button on the block
2. Confirm deletion

A block that is applied and still enabled cannot be deleted. Uncheck it, click "Apply to file", then delete it.

## External Edit Protection

If the live file was changed outside CC Switch (for example by editing `CLAUDE.md` directly), the next real write saves that file as a new **disabled backup block**, then writes the composed result. External edits are never written back into an existing block.

If a file still uses the old `## block name` join format from before this change, it is treated as in sync and is not backed up; the next apply rewrites it as a raw join.

On first launch, if an app has no prompts yet, the existing live file is imported as one applied block.

## Cross-app Usage

Prompts are managed separately per app:

- Claude shows Claude's blocks
- Codex shows Codex's blocks
- Other prompt-capable apps work the same way

To use the same content in several apps, create it separately in each.

## Import & Export

### Share via Deep Link

You can generate deep links to share prompts. If the link has `enabled=true`, import adds the block to the applied set and writes the file immediately without disabling other blocks.

### Via Configuration Export

Exporting configuration includes all prompts, which can be restored upon import.
